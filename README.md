# Vine Finder 3.0

A purpose-built Amazon Vine search command center. Built for fast, manual item discovery — no login to this website required.

## Live website

**[Open Vine Finder 3.0](https://metzger77.github.io/brads-vine-finder-3/)**

## Features

- **Smart Picks** automatically rank keywords using your recent searches, favorites, and Good Find / No Luck feedback.
- **Hunting Mode** creates a manual search route (Smart mix, favorites, tools, automotive/tractors, discovery, or broad keywords), tracks completed searches, and remembers progress after you return to the page.
- **Personal search library** retains the original 11 categories, including Milwaukee, DeWalt, other major tool brands, and John Deere 420 / 318 / 430.
- **100 broad keywords** remain available in a separate explorer.
- **Product Vault** saves Amazon item links, notes, and optional ETV values for later. It never orders anything.
- **Export / Import** lets you back up browser-local favorites, rankings, sessions, and saved product links.
- **Same tab by default**, with an optional New tab setting. Older batch-launch controls remain under Batch tools.

## Important details

The site opens Amazon Vine search URLs; it does **not** read Amazon's live item inventory, automate ordering, or guarantee $0 ETV. Check each listing yourself before requesting an item.

Your favorites, rankings, hunt progress, and saved products are kept **locally in your browser**. Use Export / Import to move data to a different browser or device. Data from the previous Vine Finder URL does not transfer automatically because each domain has separate storage.

## Development

This is a self-contained HTML/CSS/JavaScript website. Open `index.html` locally or publish the repository's `main` branch at `/(root)` through GitHub Pages. No build dependencies are required.

The previous [Vine Finder repository](https://github.com/Metzger77/brads-vine-finder) is separate and unchanged.
